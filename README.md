# 潛力工坊

天下布魔潛力素材三線排程器。這是無需建置流程的靜態 PWA；需求、剩餘流程與倒數時間會保存在目前裝置的瀏覽器。

請透過 `http://localhost:8000/` 或部署後的 HTTPS 網址開啟，不要直接雙擊 `index.html`。`file://` 網址會阻擋 Web App Manifest 與 Service Worker，素材介面也無法正常啟動。

## 手機快速預覽（同一 Wi-Fi）

1. 在 Windows 檔案總管開啟此專案資料夾，在資料夾空白處按住 Shift 再按滑鼠右鍵，選「在此處開啟 PowerShell」或「在終端機中開啟」。
2. 輸入 `node --version`。若顯示版本號（例如 `v24.15.0`），繼續下一步；若找不到 `node` 命令，直接用下方 GitHub Pages 方法。
3. 輸入以下命令啟動內附的預覽伺服器：

   ```powershell
   node preview-server.js
   ```

4. **成功啟動後視窗會留在執行中**，畫面會顯示「預覽伺服器已啟動」，不會回到 `PS C:\...>` 提示符。若立刻回到提示符，查看錯誤訊息，確認終端機目前所在路徑是本專案資料夾，而且檔案總管中看得到 `preview-server.js`。停止伺服器時按 `Ctrl+C`。
5. 在電腦另開一個 PowerShell 視窗輸入 `ipconfig`。找到目前連線的 **Wi-Fi** 區段，記下「IPv4 位址」，例如 `192.168.1.23`。不要使用 `127.0.0.1`。
6. 手機連上與電腦相同的 Wi-Fi，在手機瀏覽器網址列輸入 `http://192.168.1.23:8000`（把範例 IP 換成剛剛查到的位址）。若連不上，確認伺服器視窗仍在執行、電腦和手機在同一個 Wi-Fi，並允許 Windows 防火牆讓 Node.js 在私人網路通訊。
7. 測完後回到執行伺服器的視窗按 `Ctrl+C`。

此方法適合測試畫面、點擊和滑動。一般區域網路 HTTP 不支援本應用程式使用的 Service Worker、安裝和系統通知，因此安裝與通知要用 HTTPS 網址測試。

## 完整手機測試與安裝（GitHub Pages）

1. 登入 GitHub，按 **New repository** 建立一個 repository。若不希望其他人看到網站內容，先確認你的 GitHub 方案是否支援私人 repository 發布 Pages；公開 repository 發布的網站任何人都能瀏覽。
2. 將專案根目錄的 `index.html`、`app.js`、`styles.css`、`manifest.webmanifest`、`icon.svg`、`sw.js` 上傳到 repository 根目錄。也可以用 GitHub 網頁的 **Add file → Upload files**，拖入這些檔案後按 **Commit changes**。
3. 開啟 repository 的 **Settings → Pages**。在 **Build and deployment** 下選 **Deploy from a branch**，分支選 `main`、資料夾選 `/(root)`，按 **Save**。
4. 等待 Pages 部署完成。回到 **Settings → Pages** 頁面，開啟顯示的 `https://...github.io/.../` 網址。首次部署可能需要幾分鐘。
5. iPhone：用 Safari 開啟網址，按分享圖示 → **加入主畫面** → **加入**；從主畫面的圖示開啟，即可測試全螢幕模式。Android：用 Chrome 開啟網址，按瀏覽器選單 → **安裝應用程式**或**加到主畫面**。
6. 首次按「生產此項」時允許通知。若要測通知，先安裝 PWA、保持手機未開啟勿擾模式，並確認系統設定允許此網站／應用程式通知。

Pages 設定步驟見 [GitHub 官方說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。靜態網站不會把資料送到 GitHub：需求與倒數狀態存在使用者自己的瀏覽器本機儲存空間。若更新程式後仍看到舊版，可關閉再重開已安裝的應用程式；Service Worker 快取通常會在重新載入後更新。

## 操作方式

- 點素材卡片左半減 1、右半加 1；在卡片上按住顯示素材全名，水平左滑減 1、右滑加 1。
- 流程卡預設只顯示素材／數量標題和倒數秒數。點一張卡選取；再點已選取的卡可展開／收起各線詳情。按「生產此項」後，該項各生產線素材的需求會按共同進度扣除：共同進度是此項三線數量的最小值；同一素材若出現在多條線，按出現次數扣除。剩餘流程會保留原接續安排；手動調整需求或載入範例時再重新規劃。
- 排程優先把素材按每三種分組，同組排在三條線；最後不足三種時分配到尚可使用的生產線。對前三種素材，若數量相差很小，會留少量需求給最先完成的生產線接續，避免該線閒置。
- 倒數時間為共同進度 × 30 秒 − 15 秒。按「停止」會取消並清除倒數；到 0 會清除倒數並送出手機系統通知，通知內容指向下一項流程。提醒震動會重複到開始下一項或關閉震動；背景震動是否持續仍由手機瀏覽器與作業系統決定。
- 手機作業系統可能暫停背景網頁。重新開啟應用程式時，會依儲存的截止時間補處理逾時倒數；若瀏覽器／系統已終止網頁，不能保證倒數時間到的當刻一定送達通知。
- 範例需求的必要驗收流程為 8 項：錠錠錠 → 錠皮羽 → 牙皮羽 → 角塵鷲 → 絲絲鷲 → +角+角+晶 → +皮+羽+晶 → +牙+鷲+絲。一般需求仍使用啟發式排程，未保證所有輸入皆達全域最少操作次數。
